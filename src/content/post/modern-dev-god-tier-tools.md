这篇不是评测，也排不出什么榜。就是有人问我平时靠什么干活，我把这一年用下来真正离不开的三样东西写下来：一台 MacBook Air M5、一个叫 Typeless 的语音输入、还有 Claude Code Max。它们的共同点是，停一天我就会难受。

## MacBook Air M5

先说为什么还是 Mac。我用过几年 Windows 折腾环境变量和中文乱码，换到 Mac 之后这类问题基本不用再想了，省下来的时间和心情对我比性能参数更值钱。另外我用的几个 AI 工具，新版本经常是 macOS 先有，这点对我也算实在的好处。

配置我选的是 M5 加 32G 内存。日常写代码、开一堆浏览器标签、同时挂着 AI 工具，32G 用着很从容，没遇到过内存逼着我关东西的情况。编大项目偶尔能感觉到一点压力，但对我这种日常活儿完全够。要不要上 Pro？如果你预算够、又真的跑重负载，Pro 的天花板更高；一句话，能接受的价格里挑你买得到的最强配置就行。

## Typeless

语音输入现在选择很多，豆包输入法、微信输入法都很好用，本质上是更聪明的输入法，把你说的话变成字。我还单独用 Typeless，是因为它干的事不太一样：我经常中英文混着、逻辑也乱地嘟囔一段思路，它能把我的口头禅和废话剃掉，吐出来一段结构还算清楚的文字。说它是「整理意图」可能比「转文字」更准。

它在电脑端做得比较激进，我在 IDE、Slack、浏览器之间来回跳的时候用得最顺手。手机端我反而用得少。

价格大概 12 美元一个月（年付）。嫌贵的话有几条路：每个账号每周有 8000 字免费额度，我现在就靠这个额度用；淘宝上 300 块左右能买到年费。如果哪天开源方案追上来了，我会毫不犹豫地迁移。

开源替代值得看：[Handy](https://github.com/cjpais/Handy)。MIT 协议，跨平台（Mac / Windows / Linux），完全本地离线跑——语音不上云，按个快捷键说话，文字就出现在当前输入框里。除了 Whisper、Parakeet，它最近还内置支持了 SenseVoice，这个开源识别模型中文表现很好。装好 Handy 后在里面点一下下载安装对应模型就能用，开箱即用，不用自己折腾。单纯中文输入效果还行。

## Claude Code Max

市面上有 Codex 和 Claude Code，两者难分高下，挑一个自己合适的就好。如果懒得折腾的话，其实 Codex 用起来更舒服一点。

它分 20、100、200 三档。我用的是中间的 100 档（Max 5x），人总要花点钱才能体现一下自己的价值，应该是掉入消费主义陷阱了吧。如果能用完这个额度的话，我会觉得应该是值的。

如何订阅参考：[Claude code 订阅指南](https://blog.runningotter.com/posts/claude-subscription-guide/)

## 最后

就这三样。说是「神器」其实有点重，对我来说它们更像是已经长在工作流里、拔掉就别扭的东西。要不要为最新的 AI 工具付费，每个人账算得不一样；我的答案是，只要它每天都在帮我省时间，这钱就花得值。至于你，挑你自己真用得上的就好。
